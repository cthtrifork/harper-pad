Harper Pad key test

A throwaway page for one question: can an iPhone keep a non-extractable key in IndexedDB, sign with it, and still have it days later? It uses its own storage and touches nothing of the real app.

How to test

  1. Open this page in Safari and read the results below. Everything should say PASS.
  2. Share, Add to Home Screen, then open the new icon. A Home Screen app has its own storage, so this run starts from nothing. Read the results again: the header says "Home Screen app".
  3. Open the icon again later: after a few minutes, after a day, after a week, and after restarting the phone. Look for "Key from an earlier run survived" and read the history.
  4. Press Run Argon2id once. If the page reloads or shows WARN, memory ran out; say which size.
  5. Press Copy report and paste it back.
